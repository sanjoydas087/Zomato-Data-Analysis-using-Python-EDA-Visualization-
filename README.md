# Zomato-Data-Analysis-using-Python-EDA-Visualization-


## Overview
This project analyzes Zomato restaurant data to uncover insights about ratings, pricing, and customer preferences.

## Key Features
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Data Visualization using Seaborn & Matplotlib

## Insights
- Online ordering impacts ratings
- Most restaurants fall in mid-price range
- Ratings are clustered between 3.5–4.5

## Tools Used
- Python
- Pandas
- NumPy
- Seaborn
- Matplotlib
